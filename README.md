In Horsey Game, gene editing is mostly a trial and error process.
Please refer to the wiki at https://horseygame.miraheze.org/wiki/Genome for the most up to date information on what's been discovered so far.

---
## DNA Shortener https://zyonixgaming.github.io/dna/
* Shorten DNA to a link for sharing.
* The shortened DNA contains the full DNA data, nothing is stored on a server.
* Mobile friendly.
* Uses DNA Library. (saved in browser storage)

---
## SIMPR Horsey Genome Editor https://zyonixgaming.github.io/dna/simpr.html
* Gene Editor.
* Calculates the value for each gene pair combination.
* Mobile friendly.
* Uses DNA Library. (saved in browser storage)

---
## Visual Genome Editor https://zyonixgaming.github.io/dna/visual/
* Visual Gene Editor.
* Use sliders, checkboxes, dropdowns, color-pickers to edit your horse instead of DNA.

---
## Horsey Studio Savegame Editor https://zyonixgaming.github.io/dna/save-editor/
* Savegame Editor.
* Change the map, modify horses, add/remove items.
* Apply changes to multiple horses in bulk.
* Uses DNA Library. (saved in browser storage)
